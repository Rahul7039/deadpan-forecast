## The entry

> In Vexford, a 100% chance of rain today, all of it landing on the same parked car, which the council says is statistically overdue.

## Run it

```sh
python3 main.py
```

This writes the forecast line, byte-identical, to `/output/entry.txt`.

## About

One line, at most 160 characters: a weather forecast for a city that does not exist. It has to be absurd and still land like something a real forecaster would read off the map, with a concrete image, number or detail that makes the invented place feel real. Vexford gets all of its rain on a single parked car, and the council has the statistics to prove it was overdue.
